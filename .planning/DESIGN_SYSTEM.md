# Design System: Solução Já

## 1. Overview
The design system for **Solução Já** is built with modern, high-end visual aesthetics to impress and wow users. It uses a sleek dark mode by default, combining deep slate backgrounds with electric blue and indigo gradients, rounded cards, and elegant typography.

## 2. Typography
- **Headlines / Display**: [Outfit](https://fonts.google.com/specimen/Outfit) (Bold, modern, premium geometric sans).
- **Body / Interface**: [Inter](https://fonts.google.com/specimen/Inter) (Highly legible, crisp neo-grotesque).

## 3. Color Palette
- **Primary / Action**: `#2563eb` (Royal Blue)
- **Primary Hover**: `#1d4ed8` (Dark Blue)
- **Accent**: `#6366f1` (Indigo)
- **Urgent / Warning**: `#ef4444` (Red / Orange)
- **Background**: `#020617` (Slate 950)
- **Surface / Cards**: `rgba(15, 23, 42, 0.45)` (Glassmorphism backdrop panel)

## 4. Shapes & Roundness
- **Card Roundness**: `12px` (ROUND_TWELVE)
- **Interactive Controls (Buttons/Inputs)**: `12px`
- **Pills / Status Tags**: `9999px` (ROUND_FULL)
