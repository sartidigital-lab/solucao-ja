# Plan 01-01: Setup do Monorepo, Next.js 16 e Tailwind CSS 4

## Objective

Configurar a estrutura inicial do monorepo usando Turborepo e pnpm workspaces, contendo os aplicativos Next.js 16 (App Router) `apps/web` (PWA) e `apps/admin` (Painel Administrativo separado), além dos pacotes locais compartilhados `packages/database` e `packages/shared`, todos integrados com Tailwind CSS 4.

## Verification

### Automated Tests
- Executar `pnpm install` na raiz para garantir a resolução correta das dependências de todo o workspace.
- Executar `pnpm build` via Turborepo para garantir que a estrutura monorepo compila com sucesso.

### Manual Verification
- Rodar o servidor de desenvolvimento local (`pnpm dev`) e verificar se tanto `apps/web` quanto `apps/admin` inicializam e renderizam o estilo Tailwind CSS 4 corretamente.

## Success Criteria

1. O workspace pnpm e o Turborepo estão totalmente configurados e funcionais.
2. Ambos os aplicativos `apps/web` e `apps/admin` compilam sem erros usando o Next.js 16 e Tailwind CSS 4.
3. Os pacotes compartilhados `packages/database` e `packages/shared` são reconhecidos e importados corretamente nos aplicativos.

## must_haves

- O projeto deve ser estruturado em Monorepo com Turborepo e pnpm workspaces.
- Os aplicativos de frontend e admin devem estar usando Next.js 16 e Tailwind CSS 4 (sintaxe CSS-first).
