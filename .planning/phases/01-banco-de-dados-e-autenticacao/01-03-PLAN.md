# Plan 01-03: Implementação de Supabase Auth, Middleware de Rotas e Telas de Login/Cadastro

## Objective

Configurar a integração do Supabase Auth com Next.js 16 (App Router) via cookies usando `@supabase/ssr`, criar o middleware de rotas para aplicar guards baseados em roles (Custom Claims) e implementar as interfaces de Login (Email/Senha e Google OAuth) e Cadastro para Clientes e Profissionais.

## Verification

### Automated Tests
- Criar testes unitários para os schemas Zod em `packages/shared` garantindo validações corretas de e-mail e formato de CPF/CNPJ.
- Executar `pnpm --filter web build` para verificar se as rotas estáticas e Server Actions compilam sem erros de tipo.

### Manual Verification
- Acessar a tela de cadastro localmente, criar uma conta de cliente e uma conta de profissional.
- Validar no console do Supabase que os metadados `role` estão gravados corretamente.
- Tentar acessar rotas restritas e garantir que o middleware redireciona o usuário não autenticado para `/login`.

## Success Criteria

1. O cliente consegue efetuar login com e-mail/senha ou Google OAuth.
2. O profissional consegue se cadastrar e seus dados são persistidos nas tabelas `profiles` e `professionals` corretamente.
3. Middleware bloqueia acessos indevidos com base nos Custom Claims do JWT.
4. O logout limpa as sessões e restringe o acesso novamente.

## must_haves

- Integração completa de autenticação com cookies via `@supabase/ssr`.
- Login com Google configurado e funcional.
- Next.js Middleware de proteção de rotas com base na role (`client`, `professional`, `admin`).
- Validação pt-BR nos campos de formulário frontend.
